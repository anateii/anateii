# Hi there! <img src="https://i.ibb.co/Ydr40cV/woman-technologist-light-skin-tone-removebg-preview.png" alt="woman" width="30"> <img src="https://raw.githubusercontent.com/MartinHeinz/MartinHeinz/master/wave.gif" alt="hello" width="30">

I'm Ana, a Software Engineer based in Milan. I build the parts of the web people actually click on.

I'm still not the developer who dreams in algorithms. I'm the one who obsesses over whether a button feels right, whether a page loads fast enough, and whether the A/B test says what we hoped it would. Spoiler: sometimes it doesn't, and that's useful too.

These days I work at Rail Europe on a large Ruby on Rails app that helps travellers book trains across Europe. Most of my time goes into:

* 🧩 Building reusable UI with ViewComponent, Tailwind CSS and Stimulus
* 🧪 Running A/B tests with Kameleoon, and shipping the winners
* 🧹 Turning legacy CSS and JavaScript into something the next developer won't fear
* 📚 Writing the frontend guidelines I wish I'd had on day one

Coding found me when I wasn't sure where I was going, and it turned out to be the best medicine I've ever taken. With the help of some great mentors, it became a career I'm proud of 🥰

I still want to inspire others, especially women, to start coding. If I could do it, so can you.

## My values

* 🌱 You can't make the world better unless you keep growing yourself first
* 🔥 United we stand, divided we fall (and divided we also get merge conflicts)
* ✨ Coding is my warmup, debugging is my cardio
